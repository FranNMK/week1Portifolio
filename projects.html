My Projects

Here are three projects I've been working on — one complete, one in progress, and one that's planned but not started yet. I included planned projects because I think showing what you intend to build is just as honest as showing what you've already finished.

1. Recipe Finder App

A simple webpage where someone can browse recipes by ingredient. The layout uses a card grid and the page is fully responsive. No JavaScript — this was purely a HTML and CSS layout exercise to practise CSS Grid and semantic markup.

Status: Complete

What I Learned Building This

  • How to structure a page with semantic HTML elements
  • How CSS Grid works for card layouts
  • Why alt text on images matters for accessibility
  • How to make a page look reasonable on both mobile and desktop

2. Personal Portfolio Website

This is the site you're looking at right now. A four-page portfolio built from scratch as a Week 2 bootcamp challenge. Every line was written by hand — no templates, no frameworks, no copy-pasting from the internet.

The goal was to hit every HTML requirement from the checklist: all heading levels, multiple lists, images with alt text, a figure, a proper table, a mailto link, external links, and semantic structure on all four pages.

Status: In Progress

How I Built It (Step by Step)

  1. Planned the four pages and what content goes on each one
  2. Wrote the HTML structure for index.html first
  3. Copied the nav and footer pattern to the other three pages
  4. Filled in the content page by page, checking the requirements as I went
  5. Pushed everything to GitHub and submitted

View the repository on GitHub →

Status: Planned — starting after JavaScript fundamentals are done.

Planned Features
