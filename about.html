About Me

I'm Alex Mwangi, a self-taught web development student from Nairobi, Kenya. Here's the full story — where I came from, what made me switch paths, what I'm learning, and where I'm hoping to end up.

My Background

I grew up in Nairobi in a house where curiosity was always encouraged. As a kid I used to take things apart just to see how they worked — radios, old phones, anything I could get my hands on. That habit of wanting to understand systems never really went away.

I studied Business Administration and then spent two years in a logistics role. It paid the bills, but it left me feeling like something was missing. I wanted to build things, not just manage them. Web development gave me that.

Why Web Development?

The turning point was a Friday evening when I helped a family member put together a basic website for their small tailoring business. I expected to spend an hour on it. I looked up and it was 3 AM. I wasn't tired. I was excited.

Something clicked that night. The web is the most accessible creative medium ever invented — the tools are free, the audience is global, and the only real barrier is the willingness to sit down and learn. I enrolled in a bootcamp the following Monday.

What I'm Learning Right Now

My current focus is on the fundamentals. I want to understand HTML and CSS deeply before I rush into frameworks. A shaky foundation makes everything harder later, and I've seen enough people skip ahead and struggle to know I don't want to do that.

Core Technologies

HTML5, CSS3, and Git are my main focus right now. JavaScript is next.

Tools I Use Daily

VS Code for writing, Git for version control, GitHub to host and share my work, and the MDN Web Docs browser tab that is always open.

Editor extensions that have saved me a lot of time: Prettier, Live Server

My Skills So Far

  1. HTML5 — semantic markup, document structure, accessibility basics
  2. CSS3 — box model, flexbox, responsive design
  3. Git — committing, branching, pushing to GitHub
  4. Command line — navigating directories, running basic commands
  5. VS Code — comfortable with the editor and its extensions

My Goals for 2025

  • Complete the full web development bootcamp
  • Ship at least five real projects to GitHub
  • Land a junior developer internship
  • Make my first open-source contribution
  • Start learning JavaScript properly — not just copy-pasting snippets

Resources I Recommend

These are the sites I actually use and would genuinely recommend to another beginner:

  • MDN Web Docs — Learn Web Development — the most reliable reference I've found, full stop.
  • freeCodeCamp — free, structured curriculum with hands-on projects.
  • CSS-Tricks — every CSS question I've had has an answer here somewhere.
  • Traversy Media on YouTube — practical project-based tutorials that actually make sense.
